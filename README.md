TTool_TBS - це програма для локалізації серії ігор The Banner Saga,<br>
головною метою створення цієї програми був переклад цих ігор українською мовою

Програма дозволяє редагувати попередньо розпаковані файли локалізації гри (\*.json) 

У папці `tools` є утиліта `TBS_Decompiler_3.2.3.air` (автор jwatson000), яка дозволяє розпаковувати/запаковувати ігрові ресурси (\*.json), в яких містяться тексти до гри. Ігрові шрифти можна редагувати [цією](https://github.com/jindrapetrik/jpexs-decompiler) програмою
